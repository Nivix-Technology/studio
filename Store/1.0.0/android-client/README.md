## Nivix Store Android Client

The Android client stores its mock database locally on the device using
`@capacitor/preferences`. Spaces can be created, renamed, assigned an icon,
listed, and deleted without a desktop middleman or remote database connection.
Use **Reset Mock Database** in Settings to clear the saved spaces.

### Run and build

Run `npm start` from this directory for local development, or `npm run build`
to generate the web assets consumed by Capacitor.
